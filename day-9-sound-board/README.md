# Project 9 - Sound Board

> Project 09 of my **50 Projects in 50 Days** challenge.

## 📖 Overview

> This project creates a sound board - plays different sounds on the click of a button - using HTML5, especially the audio dag, CSS, and JavaScript. The project demonstrates DOM manipulation, audio effects, event handling, and basic layouts using flexbox.

---

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

---

## 🧠 Concepts Practiced

- Audio tag in HTML5
- DOM Manipulation
- Event Listeners
- CSS Flexbox/Grid
