# Project 13 - Event Keycodes

> Project 13 of my **50 Projects in 50 Days** challenge.

## 📖 Overview

> This project is a random choice picker, where you enter choices that you want to choose from, and it helps you choose a random one - using HTML5, CSS, and JavaScript. The project demonstrates DOM manipulation, event handling, and basic layouts using flexbox.

---

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

---

## 🧠 Concepts Practiced

- DOM Manipulation
- Event Listeners
- CSS Flexbox/Grid
