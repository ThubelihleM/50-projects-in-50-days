# Project 17 - Movie App

> Project 17 of my **50 Projects in 50 Days** challenge.

## 📖 Overview

> This project displays movies that we fetch from an external API - using HTML5, CSS, and JavaScript. The project demonstrates DOM manipulation, APIs, event handling, and basic layouts using flexbox.

---

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

---

## 🧠 Concepts Practiced

- APIs and promises
- DOM Manipulation
- Event Listeners
- CSS Flexbox/Grid

---
