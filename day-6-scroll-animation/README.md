# Project 6 - Scroll Animation

> Project 06 of my **50 Projects in 50 Days** challenge.

## 📖 Overview

> This project creates a scroll animation widget using HTML, CSS, and JavaScript. This widget can be used in larger project to inhance interactivity. The project demonstrates DOM manipulation, event handling, and basic layouts using flexbox.

---

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

---

## 🧠 Concepts Practiced

- DOM Manipulation
- Event Listeners
- CSS Flexbox
