# Project 11 - Event Keycodes

> Project 11 of my **50 Projects in 50 Days** challenge.

## 📖 Overview

> This project displays keycodes for keyboard click events - using HTML5, CSS, and JavaScript. The project demonstrates DOM manipulation, event handling, and basic layouts using flexbox.

---

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

---

## 🧠 Concepts Practiced

- Event Listeners
- CSS Flexbox/Grid
